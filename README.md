# Лендинг психолога Елены Залевской

Статический адаптивный сайт, готовый к размещению на GitHub Pages. Сборка и установка зависимостей не требуются.

## Быстрый запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Публикация на GitHub Pages

1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите в корень репозитория всё содержимое этой папки.
3. Выполните первый коммит в ветку `main`.
4. Откройте **Settings → Pages → Build and deployment**.
5. В поле **Source** выберите **GitHub Actions**.
6. Дождитесь выполнения процесса **Deploy website to GitHub Pages** во вкладке **Actions**.

Файл `.github/workflows/pages.yml` уже содержит готовую автоматическую публикацию. После каждого изменения в ветке `main` сайт будет обновляться автоматически.

## Подключение своего домена

1. Настройте DNS-записи домена по инструкции GitHub Pages.
2. Скопируйте `CNAME.example` в файл `CNAME`.
3. Впишите в `CNAME` выбранный домен, например `zalevskaya.ru` или `zalevskaya.pro`.
4. Включите **Enforce HTTPS** в настройках GitHub Pages после успешной проверки DNS.

Не добавляйте `https://` и `www` в файл `CNAME`, если домен используется без `www`.

## Что изменить перед публикацией

Контактные кнопки сейчас ведут на текущую страницу Елены:

```text
https://taplink.cc/zalevskaya
```

Если есть прямые ссылки на Telegram, WhatsApp или сервис записи, найдите этот адрес в `index.html` и замените его на нужную ссылку.

## Структура

```text
index.html                  основная страница
styles.css                  стили и адаптивная версия
script.js                   меню, анимация и текущий год
assets/                     оптимизированные фотографии
.github/workflows/pages.yml автоматический деплой GitHub Pages
.nojekyll                   отключение обработки Jekyll
```
